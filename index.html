          About the reference ranges
          
      Ranges are typical values for healthy adults from published guidelines. A chest strap is a single, non-standard ECG lead, so values outside a range are a prompt to look closer, not a diagnosis. Heart-rate and HRV ranges apply to resting recordings only and adjust to the age and sex in Settings.

        About
        
        
        OpenBeat ECG is free to use. Recordings stay on this device (browser storage); nothing is uploaded.
        
        
        Requires a browser with Web Bluetooth: Chrome or Edge on Windows, macOS, Linux, ChromeOS or Android. On iPhone/iPad use the Bluefy browser. Demo modes work everywhere.
